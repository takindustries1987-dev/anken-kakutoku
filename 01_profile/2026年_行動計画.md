# 2026年 行動計画

※六星占術（水星人−・健弱年）、**四柱推命_report.md**（丙午年・辛丑大運）、**算命学.md**、性格プロファイルを踏まえた年間設計です。  
占いは意思決定の「補助線」として使い、健康・お金・法務は必要に応じて専門家も併用してください。

## 1. 2026年の大テーマ（年間方針）

| キーワード | 内容 |
|---|---|
| **年運（六星）** | 健弱（小殺界）＝疲れが表面化しやすい年 |
| **年運（四柱推命）** | 丙午＝火が非常に強い年。信用・規律・監査耐性が試される。ルール整備・証跡・再現性で取りに。例外運用を減らし休息も“運用”に |
| **年運（算命学）** | 忙しくなりやすい・勝負どころが増える・試行錯誤が増える。「増やす」より**“絞る”**が運を良くするコツ |
| **方針** | **整備・回復・基礎固め**。大きく伸ばすより、崩れない体制づくりが得点。 |
| **最優先KPI** | **健康**（睡眠と疲労管理）。これが守れた時点で勝ち。 |
| **攻めの月** | 5月・7月・10月・11月に「前進」を寄せる（六星）。四柱推命の月運も下記で併用。 |
| **守りの月** | 1〜2月・8月・12月は守りと回復に寄せる |

### 性格との合わせ方
- **抱え込み防止**：上位3つ以外は停止／保留／委任（ENFJの枝増やし防止）
- **定義を曖昧にしない**：目的・制約・Doneをテンプレで固定してから動く。**条件を最初に紙に**（算命学）
- **一本化**：3か月単位で「今期はこれ一本」、週1で「やらないこと」を確定（算命学）
- **「気合で乗り切る」は禁止**：疲れ→判断鈍り→約束過多・対人摩擦が増える（健弱年あるある）
- **休息の運用化**：週1完全オフを予定としてロック（四柱推命）

## 2. 分野別・年間の行動指針

### 仕事
- **向くこと**：業務の棚卸し、標準化、契約/請求/会計の整備、仕組み化、既存案件の回収率UP。合意形成の型（打合せ→議事録→次アクション表）、単価設計の再定義（作業範囲と成果範囲を分けて提示）（四柱推命）
- **向かないこと**：過剰な拡大、睡眠を削る運用、短期で結果を急ぐ賭け。責任だけ重く権限・条件が曖昧な案件、ノリで始まり運用設計がない案件（算命学）
- **勝ち筋**：「新規獲得」より「既存の回収率UP」— 請求漏れゼロ、単価調整、紹介導線の整備。選別と単価設計を先にやる（四柱推命）

### お金
- **基本**：「貯める」より「減らさない」— 固定費・サブスク・手数料の見直し。収益の見える化（月次PL、案件別粗利、工数ログ）、例外の撲滅（四柱推命）
- **増やすなら**：**10月（財成）**で契約/単価改定/値上げ交渉/収益化を狙う。作業単価→成果単価（運用改善）へ（四柱推命）
- **NG**：レバレッジ強めの投機、衝動買い、根拠薄い高額契約。**熱くなって前のめり投資**（算命学）。投資・大きな支出は「上限損失・撤退条件・検証期限・成功条件」を先に決めてから（算命学）

### 恋愛・対人
- **テーマ**：誤解を減らす＝「希望・境界線」を誠実に共有。「好き」「助かる」を言語で出す。指摘は「提案→選択肢→相手に決めさせる」の順（四柱推命・正論の丸め）
- **忙しい時のルール**：連絡頻度・会うペース・急用時を先に決めておく（水星人−は行動だけだと伝わりにくい）

### 健康（最優先）
- **必須**：睡眠（毎日同じリズム）、定期検診、続けられる軽い運動
- **やると効く**：週1の完全オフ or 軽作業日／回復ルーチン固定（入浴・ストレッチ・散歩）／体調ログ（睡眠・頭痛・胃腸など）
- **受診**：痛み・しびれ・睡眠障害・メンタル不調が続いたら早めに医療機関へ

## 4. 月別・具体的アクション例（チェックリスト用）

### 1月・2月（守り・回復）
- [ ] 睡眠時間と起床時刻を固定する
- [ ] 大決断・新規大型案件は保留
- [ ] 固定費・サブスクの一覧化だけする（削る判断は後で）
- [ ] 体調ログを始める（睡眠・疲労感・頭痛など）

### 3月・4月（種まき・整備）
- [ ] 既存案件の単価・粗利・工数を1表にまとめる
- [ ] 手順書・テンプレを1つだけ作る（完璧を目指さない）
- [ ] 収支の棚卸し（財布を生活/事業/投資に分ける検討）
- [ ] 週1の完全オフ or 軽作業日をカレンダーにブロック

### 5月・7月（攻め・前進）
- [ ] 見せ方・提案・単価UPの検討と小さな実行
- [ ] 締め切り・成果物を1つ「完了」に持っていく
- [ ] 請求漏れゼロ確認・回収の締め
- [ ] 休息日を成果出しの直後に必ず入れる

### 6月（健弱・ペース配分）
- [ ] 新規の抱え込みをしない（断る／範囲縮小の練習）
- [ ] 医療費・想定出費をメモして予算感を持つ
- [ ] 気遣い過多になっていないか振り返る

### 8月・12月（守り・乱気/陰影）
- [ ] 大きな勝負・投機・大支出は避ける
- [ ] 関係のすれ違いは「言語化」でフォロー（希望・境界線を短く伝える）
- [ ] 棚卸し・来年の計画のたたき台だけ作る
- [ ] 受診が必要なら予約する

### 9月・10月・11月（再会・財成・安定）
- [ ] 過去の縁・紹介・コミュニティ由来の再提案を動かす
- [ ] 10月：契約/単価改定/値上げ交渉のタイミングに据える
- [ ] 11月：貯蓄・積立・定着運用のルールを決める
- [ ] 働き過ぎていないか週次でチェック

## 5. 年間で必ずやる・やらない（自分との約束）

### 必ずやる
1. **睡眠リズムの固定**（毎日同じ時刻に寝る/起きるを最優先）
2. **今週の上位3つ**を日曜 or 月曜に決め、それ以外は停止/保留/委任と書く
3. **意思決定テンプレ**を毎回使う（目的・制約・Done・やらないこと・次の一手）
4. **10月に「金の成果」**を1つ狙う（契約/単価/値上げのどれか）
5. **体調ログ**を最低でも週1回つける（崩れ始めを早く拾う）
6. **合意形成の型**：打合せ→議事録→次アクション表を固定（四柱推命）
7. **週1の完全オフ**を予定としてロック（四柱推命・休息の運用化）
8. **3か月単位で「今期の一本」**を決め、週1で「やらないこと」を確定（算命学）

### やらない
1. 睡眠を削っての無理な締め切り受諾
2. 定義・スコープ・Doneがないまま「とりあえず」で進める
3. 8月・12月の大勝負・大支出・感情任せの決断
4. 新しいアイデアの即実行（保留欄に入れて、1週間後に見る）
5. 「自分が全部やらなきゃ」が続く状態を2週間以上放置しない
6. 例外運用を証跡なし・期限なしで残す（四柱推命）
7. 熱くなって前のめりの投資・大支出（算命学）。投資は上限損失・撤退条件・検証期限を先に決める

### 四柱推命「やると勝つ」チェックリスト（実装用）
| 分類 | 1番効く打ち手 | すぐできる最小アクション |
|---|---|---|
| 仕事 | 合意形成の型 | 打合せ→議事録→次アクション表を固定 |
| 金 | 単価設計の再定義 | “作業範囲”と“成果範囲”を分けて提示 |
| 相性 | 正論の丸め | 指摘は「提案→選択肢→相手に決めさせる」順 |
| 体調 | 休息の運用化 | 週1回の完全オフ（予定としてロック） |

### 算命学「一本化」テンプレ（今期用）
| 項目 | 記入例 |
|---|---|
| 今期（3か月）の一本 | 例：◯◯案件を商品化して月◯件獲得 |
| やらないこと3つ | 例：新規プロジェクト開始／無料相談の無制限対応／夜中の意思決定 |
| 週次チェック | 例：金曜に売上・進捗・未完了を棚卸し |
| 捨て基準 | 例：2週間進捗ゼロなら停止／利益率◯%未満は改善か終了 |

## 6. 今年の結論（短く）

- 2026年は**壊さず積み上げる年**。「増やす」より**絞る**（算命学）。攻めるなら**5月・7月・10月・11月**に前進を寄せる。
- **1〜2月・8月・12月**は守りと回復。最優先KPIは**健康**。四柱推命の月運（立春基準）も参照して月ごとのテーマを合わせる。
- 信用・規律・証跡・再現性で取りに（四柱推命・丙午）。条件を最初に紙にし、例外は期限・証跡つきで固定。
- 性格の強み（責任感・統率・再現性）は「基準とDoneの明文化」「上位3つルール」「一本化」で活かし、抱え込みと枝増やしを止める。
