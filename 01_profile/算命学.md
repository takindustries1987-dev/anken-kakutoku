# 算命学（大衆向け）リーディングまとめ（暫定）

対象データ：1987-05-11／出生地：石川県／出生時間：昼〜夕方（概ね）  
※出生時間が曖昧でも、今回の「大枠の結論」は大きくは変わりません。相性や細部の精度は、出生時間が絞れるほど上がります。

---

## 1. あなたの基本性格（ざっくり結論）

- **派手に目立つより「現場を回して成果を出す」タイプ**  
  運用・整備・改善・仕組み化が得意です。
- **責任感が強く、約束やルールを大事にする**  
  条件が曖昧な話／筋の悪い案件だと、ストレスが一気に増えやすい。
- **自立心が強い**  
  “管理される”より、“任される”環境で力が出ます。
- **学びながら直していく力がある**  
  ただし、同時並行を増やしすぎると散りやすいので「絞り込み」が鍵。

---

## 2. 仕事：向いてる勝ち方

### 2-1. 得意な領域
- 業務の**手順化／マニュアル化／チェックリスト化**
- 品質を安定させる（ミスを減らす、再発防止）
- 数字で管理（時間、件数、原価、利益率）
- 仕組みを作って「人に渡せる形」にする（属人化を減らす）

### 2-2. 失敗しやすいパターン（ここ注意）
- **責任だけ重く、権限や条件が曖昧**（丸投げ／後出し条件追加）
- “ノリ”で始まり、運用の設計がない案件

### 2-3. 実務の対策（これが効く）
最初に「条件を紙にする」ほど勝ちます。

| 最初に決めること | 例 |
|---|---|
| 仕事の範囲 | どこまでやる／どこから先は別料金 |
| 期限 | いつまでに何を出す |
| 決裁者 | 誰が最終判断するか |
| 例外時 | 追加作業・仕様変更の扱い |
| 報酬 | 単価・支払い条件・遅延時の対応 |

---

## 3. お金：増やし方・守り方

- **一発逆転より「漏れを止める」「積み上げる」で増えるタイプ**
- 固定費の最適化、継続課金、単価アップ、外注・仕入れ設計が向きます
- 注意点は **“熱くなって前のめり投資”**

### お金の意思決定ルール（おすすめ）
投資や大きな支出は、先にこれを決めてから動くと事故が減ります。

| ルール | 例 |
|---|---|
| 上限損失 | 「ここまで損したら止める」 |
| 撤退条件 | 「こうなったら撤退」 |
| 検証期限 | 「◯週間で判断」 |
| 成功条件 | 「これが達成できたら継続」 |

## 4. 相性（恋愛・家庭／仕事パートナー）

### 4-1. 恋愛・家庭の相性
合いやすい：
- 落ち着いていて生活が安定している
- 約束を守る／段取りができる／現実感がある

合いにくい：
- 勢いだけで動く
- 言うことが頻繁に変わる
- 話がふわっとしていて運用が弱い

あなたが「後始末係」になりやすいので、**生活の現実面（お金・時間・約束）を一緒に守れる相手**が強いです。

### 4-2. 仕事パートナーの相性
- あなたは「回す・整える・強くする」が得意
- 相棒は「取ってくる・広げる」が得意だと噛み合います

ただし相棒が拡張型だと暴走しやすいので、あなたが**ルール決め担当（ブレーキ役）**として権限を持つ形が強いです。

## 5. 2026年の流れ（使い方）

今年は一言でいうと：
- **忙しくなりやすい**
- **勝負どころが増えやすい**
- **試行錯誤が増えやすい**

だから、運を良くするコツは「増やす」より **“絞る”** です。

### 今年の勝ち筋（具体）
- 3か月単位で「今期はこれ一本」を決める
- 週1回、整理の日を作って「やらないこと」を確定する
- お金は「拡大投資」より「運用強化の投資」（道具・外注・仕組み）に寄せると回収しやすい

---

## 6. すぐ使える「一本化」テンプレ（おすすめ）

| 項目 | 記入例 |
|---|---|
| 今期（3か月）の一本 | 例：◯◯案件を商品化して月◯件獲得 |
| やらないこと3つ | 例：新規プロジェクト開始／無料相談の無制限対応／夜中の意思決定 |
| 週次チェック | 例：金曜に売上・進捗・未完了を棚卸し |
| 捨て基準 | 例：2週間進捗ゼロなら停止／利益率◯%未満は改善か終了 |
