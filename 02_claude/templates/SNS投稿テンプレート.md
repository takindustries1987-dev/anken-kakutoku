# SNS投稿テンプレート

使い方：{} 部分を書き換えてそのまま投稿する。考えすぎない。

---

## X（メイン発信）

### ① 毎日の進捗報告

```
【Day {X}】今日の案件獲得活動

・応募: {X}件
・受注: {X}件
・学び: {1行で書く}

#クラウドソーシング #案件獲得 #AI活用
```

### ② 学び共有（失敗談/発見）

```
{何が起きたか1行}

結論: {学んだこと1行}

これから{次にどうするか1行}

#フリーランス #副業 #AI活用
```

### ③ 週次報告

```
【週次報告 Week {X}】

応募: {X}件 → 受注: {X}件
売上: ¥{XX,XXX}

{一言コメント（例：初受注できた！/応募文を改善したら返信率が上がった）}

#案件獲得 #クラウドソーシング #副業
```

### ④ 初投稿（チャレンジ宣言）

```
今日からクラウドソーシングで案件獲得チャレンジ始めます。

目標: 2週間で5件受注
武器: AI（Claude/ChatGPT）を活用した高速納品
PF: CrowdWorks / ランサーズ

過程をリアルに発信していきます。
うまくいったこと・失敗したこと、全部出します。

#案件獲得チャレンジ #AI活用 #フリーランス
```

### ⑤ 案件タイプ紹介

```
AIを使うとこんな案件が{時間}で終わる：

・{案件タイプ}（{単価}円）
・やること：{1行で内容}
・使うツール：{Claude + Python/GAS等}

再現性あるので、プログラミング初心者でもいけると思う。

#AI活用 #副業 #クラウドソーシング
```

## Threads（Xの転載 + コミュニティ交流）

基本はXと同じ内容を転載。以下の調整だけする：

- ハッシュタグを減らす（2〜3個に）
- 語尾をカジュアルに（「〜した」→「〜した！」）
- 質問で終わる投稿も入れる（「みんなはどうしてる？」）

### Threads用アレンジ例

```
案件獲得チャレンジ Day {X}

今日は{X}件応募した。
{1行で感想}

同じようにクラウドソーシングやってる人いたら、コツ教えてください！

#フリーランス #副業
```

## Instagram（週次ビジュアルまとめ）

### カルーセル投稿の構成（5〜7枚）

| スライド | 内容 |
|---------|------|
| 1枚目（表紙） | 「Week {X} まとめ｜案件獲得チャレンジ」 |
| 2枚目 | 今週の数字（応募数・受注数・売上） |
| 3枚目 | 今週やったこと（箇条書き3〜5個） |
| 4枚目 | 学んだこと・気づき（1〜2個） |
| 5枚目 | 失敗したこと（1個） |
| 6枚目 | 来週の目標（1〜2個） |
| 7枚目（CTA） | 「フォローで毎週の進捗をチェック！」 |

### キャプション

```
【Week {X} まとめ】案件獲得チャレンジ

📊 今週の成果
・応募: {X}件
・受注: {X}件
・売上: ¥{XX,XXX}

💡 学んだこと
{1〜2行}

❌ 失敗したこと
{1行}

🎯 来週の目標
{1行}

---
AI×クラウドソーシングで案件獲得する過程をリアルに発信中。
再現性のある方法だけを共有します。

#案件獲得 #フリーランス #副業 #AI活用 #クラウドソーシング
```

---

## 発信ルール（守ること）

1. **数字は正直に出す**（盛らない）
2. **具体例で語る**（抽象的な意識高い系にならない）
3. **再現性を意識**（他の人もマネできる形で書く）
4. **テンプレに数字を埋めるだけ**にする（考えすぎて投稿しない、を防ぐ）
5. **1日1投稿が最低ライン**（X or Threads どちらか1つでOK）
