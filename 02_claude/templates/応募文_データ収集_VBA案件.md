## カスタマイズのポイント

1. **データ収集案件**は要件がシンプルなので応募文も短めでOK
2. **VBA案件**は「ボタン1つで実行」を強調 → クライアントの安心感
3. 金額は案件のデータ量や作業量を見て設定。データ収集は時間単価で考える
4. VBA案件はサンプルExcelを共有してもらうよう促す

## よく使うVBA案件の具体提案文パーツ

| 案件内容 | 提案文パーツ |
|---------|-----------|
| 月次集計 | 「指定条件でデータを集計し、サマリーシートに自動出力するマクロを作成します」 |
| データ転記 | 「複数シート/ファイルから指定項目を統合シートに自動転記するマクロを作成します」 |
| 帳票作成 | 「入力シートのデータをもとに、指定フォーマットの帳票を自動生成するマクロを作成します」 |
| PDF出力 | 「シートごとにPDFを自動出力し、指定フォルダに保存するマクロを作成します」 |
| メール送信 | 「Excelの宛先リストをもとにOutlookから自動メール送信するマクロを作成します」 |
