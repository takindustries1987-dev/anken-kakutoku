# 応募文テンプレート — GASスクリプト作成案件

使い方：{} 部分を案件に合わせて書き換えてコピペする。
所要時間の目安：15分以内

---

## テンプレート

```
{クライアント名} 様

はじめまして、{自分の名前}と申します。
{案件名}のご依頼を拝見し、ご応募させていただきます。

Google Apps Script（GAS）を活用した業務自動化を得意としており、
ご依頼内容に対応可能です。

■ 対応可能な理由
・GASによるスプレッドシート操作・自動化の実績があります
・{案件に関連する具体的な経験/スキル}
・AIを活用した効率的な開発で、スピーディに納品可能です

■ ご提案内容
{案件の要件を読んで、具体的にどう実現するか2〜3行で}

例：
- スプレッドシートの売上データを自動集計し、Slackに通知するGASスクリプトを作成します
- トリガー設定により毎日自動実行される仕組みにします
- 操作マニュアルも合わせて納品します

■ 納期
・{X}営業日以内（ご要件確認後、正確な日程をお伝えします）

■ お見積もり
・{金額}円（税込）
・含む範囲：GASスクリプト本体 + 簡易マニュアル + 納品後7日間の修正対応

■ 進め方
1. ご発注後、詳細要件のヒアリング（スプレッドシートの構成等）
2. 開発 → 途中経過のご報告
3. テスト環境での動作確認
4. 納品 → 動作確認 → 修正対応

■ 稼働について
・レスポンス：原則24時間以内
・稼働時間：{平日○時〜○時}

ご不明な点がございましたら、お気軽にご連絡ください。
ご検討のほど、よろしくお願いいたします。
```

---

## カスタマイズのポイント

1. **冒頭2行目**で「GASを得意としている」ことを明示 → クライアントの安心感
2. **ご提案内容**は案件ごとに必ず書き換える（ここがテンプレ感を消す鍵）
3. **金額**は案件の提示額の範囲内で設定。迷ったら案件提示額の下限〜中間
4. **納期**は余裕を持つ。実際1-2時間で終わる案件でも「3営業日以内」にしておく

## よく使うGAS案件の具体提案文パーツ

| 案件内容 | 提案文パーツ |
|---------|-----------|
| スプレッドシート集計 | 「指定のシートから条件に合うデータを自動集計し、サマリーシートに出力するGASを作成します」 |
| メール自動送信 | 「スプレッドシートの宛先リストをもとに、GmailAPIでメールを自動送信するスクリプトを作成します」 |
| フォーム連携 | 「Googleフォームの回答をトリガーに、スプレッドシートへの自動記録＋通知を行うGASを構築します」 |
| Slack/LINE通知 | 「スプレッドシートの更新をWebhookでSlack/LINEに自動通知する仕組みを作成します」 |
| カレンダー連携 | 「スプレッドシートのスケジュールデータをGoogleカレンダーに自動登録するGASを作成します」 |
