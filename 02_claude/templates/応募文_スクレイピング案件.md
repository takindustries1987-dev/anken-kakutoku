# 応募文テンプレート — Webスクレイピング案件

使い方：{} 部分を案件に合わせて書き換えてコピペする。
所要時間の目安：15分以内

---

## テンプレート

```
{クライアント名} 様

はじめまして、{自分の名前}と申します。
{案件名}のご依頼を拝見し、ご応募させていただきます。

PythonによるWebスクレイピング・データ収集を得意としており、
ご依頼内容に対応可能です。

■ 対応可能な理由
・Python（BeautifulSoup/Selenium/Playwright）でのスクレイピング実績があります
・{案件に関連する具体的な経験/スキル}
・取得データの整形・CSV/Excel出力まで一貫して対応可能です

■ ご提案内容
{案件の要件を読んで、具体的にどう実現するか2〜3行で}

例：
- ご指定のサイトから商品名・価格・在庫情報をPythonで自動取得します
- 取得データはCSV形式で出力し、そのままExcel/スプレッドシートで利用可能です
- 定期実行が必要な場合はスケジューラ設定もご相談可能です

■ 技術選定
・静的サイト → BeautifulSoup + requests（高速・軽量）
・動的サイト（JS描画あり）→ Playwright/Selenium（確実にデータ取得）
・出力形式：CSV / Excel / Googleスプレッドシート

■ 納期
・{X}営業日以内（対象サイトの構造確認後、正確な日程をお伝えします）

■ お見積もり
・{金額}円（税込）
・含む範囲：スクレイピングスクリプト + 取得データサンプル + 簡易マニュアル + 納品後7日間の修正対応

■ 進め方
1. ご発注後、対象サイト・取得項目のヒアリング
2. サイト構造調査 → 技術選定
3. 開発 → サンプルデータで動作確認
4. 納品 → 最終確認 → 修正対応

■ 稼働について
・レスポンス：原則24時間以内
・稼働時間：{平日○時〜○時}

■ 注意事項
・対象サイトの利用規約に反するスクレイピングはお受けできません
・ログインが必要なサイトの場合は事前にご相談ください

ご不明な点がございましたら、お気軽にご連絡ください。
ご検討のほど、よろしくお願いいたします。
```

---

## カスタマイズのポイント

1. **技術選定**セクションで具体的なライブラリ名を出す → 技術力のアピール
2. **ご提案内容**で「何を」「どうやって」取得するか具体的に書く
3. **注意事項**は必ず入れる（利用規約違反の案件を避ける防衛線）
4. **金額**はページ数やデータ量で見積もりが変わるので「詳細確認後に最終お見積もり」としてもOK

## よく使うスクレイピング案件の具体提案文パーツ

| 案件内容 | 提案文パーツ |
|---------|-----------|
| ECサイト商品情報 | 「商品名・価格・レビュー数・在庫状況を一覧取得し、CSVで出力します」 |
| 不動産情報 | 「物件名・価格・面積・最寄り駅を一括取得し、比較表として出力します」 |
| 求人情報 | 「求人タイトル・給与・勤務地・応募条件を取得し、条件でフィルタリングした一覧を作成します」 |
| 口コミ・レビュー | 「レビュー本文・評価・投稿日を取得し、分析しやすい形式で出力します」 |
| 競合調査 | 「指定URLから価格・商品スペック等を定期取得し、差分を検出する仕組みを構築します」 |
