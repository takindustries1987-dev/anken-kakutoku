# 井出さん SNSマーケティング フレームワーク
**出典**: 第19回 Zoom勉強会 (2026-04-07) - 井出さんパート [32:18〜1:42頃]

## トピック一覧（網羅）

### 1. バズは目的ではない / むしろ悪種になり得る
- バズは基本的にいらない。売上・仕事獲得が目的なら不要
- バズを狙う気持ちが先行すると悪種（逆効果）になる
- **バズが正義になる例外**: インフルエンサー志望、低単価アフィリエイト、低CVR大量認知モデル

### 2. フォロワー数は売上に直結しない
- 実例: MBTIx恋愛のインスタアカウント、月2000万インプレッションでも売上は最高月40万
- フォロワー数万人いても売上・仕事獲得にはあまり関係ない
- 少ないフォロワー（100人でも）で仕事・売上は立てられる

### 3. 氷山モデル: 表層テクニック vs 本質（コンセプト設計）
- **水面上（2割）**: バズるライティング、コピーライティング、サムネ、表現テクニック
- **水面下（8割）**: アカウントのコンセプト、ポジション取り
- 表層だけ頑張っても売れない・お客様につながらない
- コピーが強くても「うさんくさい奴らのうちの一人」に見えてフィルタリングされる

### 4. ポジション設計（最重要）
- SNS上での「自分の立ち位置」を明確にすることが全て
- ポジション = 3つの円の交差点:
  - **自分の強み（オンリーワン）**
  - **自分のストーリー（老い立ち・経験）**
  - **お客さんのニーズ**

### 5. 「強み」ではなく「オンリーワン」で考える
- 強みという言葉を忘れて「オンリーワン」で捉える
- 恋愛の例え: イケメンだけが強みではない。「かっこよくない」ことすら誰かにとっての魅力になる
- 弱みや個性が、特定の誰かに刺さる強みになる
- ADHDのようなハンディキャップもSNSでは個性として機能する
- オンリーワンの見つけ方: AIと壁打ちするのが有効

### 6. 色の限界（印象は2つまで）
- 1人のアカウントに付けられる印象は最大2つが限界
- 例: 「ADHDでAI強い人」→ これくらいが限界
- 3つ以上の要素を盛り込むとぼやける
- 2つの掛け算で差別化するのが最適

### 7. リアルなエピソードの力（嘘はバレる）
- AI時代でもリアルなストーリーは人を動かす
- AIで作ったストーリーは「よくある話」になりがちで深みが出ない
- 人間は無意識に嘘を見抜く（間合い、表現、単語選び、目の動き）
- 井出さんの実例: ガソスタ夜勤 + 動画編集 + リベルサスで食費節約 → AIでは発想できない組み合わせ
- 嘘の話にはノイズが混ざり、信頼度が下がる

### 8. プレイヤー視点 vs メタ視点
- **プレイヤー視点（NG）**: どうバズらせよう、どう伸ばそう、サムネどうしよう → 沼にハマる
- **メタ視点（推奨）**: SNSという海の中で、自分はどこにピンを立てたら求めるお客様を集められるか
- 俯瞰して考えることが8割。井出さんはAI仙人のYouTube開始時に「死ぬほど考えた」

### 9. 「あなたの発信を見る理由は一切ない」という前提
- SNS上では自分は何者でもない（フォロワー0人の状態）
- 数万〜数百万のインフルエンサーがいる中で、自分を見てくれるはずがない
- この厳しい前提から「見ざるを得ない理由」を考え抜く
- SNSプラットフォームも見られないアカウントを推薦するメリットがない

### 10. 感情を揺らすフック（引っかかる仕掛け）
- 人間の脳は99.何%の情報を捨てている → 残る0.何%に入る必要がある
- 「重要」= 崇高なものだけでなく、本能的に心が揺れるもの
- 感情の揺らし方: プラスでもマイナスでもいい。何も感じさせないのが最悪
- AI仙人の実例: 変態仮面（なんやこれ）、歯が腐ってる（何それ）→ 感情が動く
- 「年収1億」は距離が遠すぎてスルー。「年収1000万（笑）」は絶妙にムカつくからクリック

### 11. 距離感のコントロール（近すぎず遠すぎず）
- 近すぎる → お友達になってサービス購入に至らない
- 遠すぎる → 「すごいね」で離脱、自分ごとにならない
- 適切な距離感: 共感できるけど、今の自分では達成できない何かがある
- 距離をあえて離す場面もある（B2Bの信頼構築など）

### 12. 顔出し・声出しの重要性
- 基本的に顔出し・声出しした方がいい
- 人間は作られたものより生身の人間の方が頭に入りやすい
- 出せない場合は別のフック（変態仮面のような代替手段）が必要

### 13. 競合リサーチの方法
- フレームワークやマトリックスは使わない（井出さんの場合）
- 伸びてる人の投稿を片っ端から見る → なぜ伸びてるかを分析
- 伸びてない人も見る → 「こうしたら伸びない」が明確になる
- TTP（徹底的にパクる）は良くない。真似ではなく、空きポジションを見つける
- **視聴者の気持ちで見る**ことが最重要

### 14. 煽り系コピーの問題
- 2017年頃は効いたが、今は煽りコピーが溢れすぎて逆効果
- 読む前に「うさんくさい」とフィルタリングされて頭に入らず離脱
- 表現テクニックは必要だが、ポジションが弱いと無意味

### 15. 発信内容の2種類と比率
- **集客投稿（ノウハウ系）**: お客さんが集まりやすい。初見でクリックされやすい
- **ファン化投稿（エピソード系）**: 自分のストーリー・人柄を伝える。「この人から買いたい」につなげる
- ノウハウだけだと「他の人でもいい」になる
- **比率の目安**: フォロワー1000人未満はノウハウ多め → 1000人超えたらノウハウ6-7割、エピソード3割

### 16. ペルソナとカスタマージャーニー
- ペルソナは作る。カスタマージャーニーは頭の中にある（経験で体得）
- アカウント立ち上げ時: ペルソナは**1人**に絞る
- アカウントが大きくなったら: **3人**程度に拡大
- 一人に向けて発信するからこそ、その属性の人に深く刺さる

### 17. SNSは顧客優位の世界
- 対面営業と違い、物理的な制約がない（圧をかけられない）
- お客さんはベッドの上でぼーっとスマホを見ている状態
- その状態で信頼を勝ち取るには嘘が致命的

### 18. キャラ変について
- フォロワー1000人未満ならキャラ変してもバレない。今日からやっていい
- 極端すぎる変更（仏→詐欺師）でなければ問題ない

### 19. テンプレートの使い方
- 完全初心者がゼロからやるよりテンプレで型を知るのは良い
- ただしテンプレに固執すると一生沼る
- 型を知った上で、自分のポジションに合わせてカスタマイズする

### 20. 視聴者目線になるコツ
- **ぼーっと見る**のが最大のコツ
- 集中して見ると作り手目線になってしまう
- 眠い状態であえて見る → 頭に入ってこない部分 = 視聴者にとってのノイズ
- ノイズはどんなにおしゃれなツッコミでも泣く泣くカットする

### 21. B2B商材の場合
- 代表のビジョンとその背景（経験）を出す → 属人的になるのが良い
- 完全無形のB2Bは難しい → 広告（資本力）の方が向くケースもある

### 22. SNS自動化の適用範囲
- 向いている: 低単価アフィ、数の暴力型、ファン不要モデル
- 向いていない: 自分が前に立つファン化型 → エピソードやコンテキストが重要
- AIコンテキストを組み込めば「比較的」運用しやすくはなる

### 23. 井出さんの愛用フレームワーク（予告）
- 「ワクワクする存在であること」「卓越性があること」「現在の自分では達成できない」
- この3要素のフレームワークを愛用（詳細は次回）

## 判断基準まとめ

| 判断軸 | やるべき | やらないべき |
|--------|----------|-------------|
| バズ | 認知ゼロ状態での大量露出モデルのみ | 売上・仕事獲得が目的の場合 |
| フォロワー数 | 質の高い少数ファン | 見かけの数を追う |
| コピー | ポジションが固まった上での表現磨き | ポジション不在でのテクニック頼り |
| 自分語り | リアルなエピソードをノウハウに混ぜる | 嘘のストーリー / ノウハウだけ |
| 競合 | 空きポジションを見つける | 伸びてる人をそのまま真似る |
| ペルソナ | 1人に絞って深く刺す | 全員に向けてぼやかす |
| 自動化 | 低単価・大量販売モデル | ファン化が必要なモデル |
