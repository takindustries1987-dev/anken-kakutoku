## 1. CrowdWorks

### 1-1. 新規登録

1. https://crowdworks.jp にアクセス
2. 「会員登録（無料）」をクリック
3. メールアドレスを入力 → 確認メール受信 → URLクリック
4. ユーザー名・パスワード・氏名・生年月日・住所を入力
5. 「ワーカー（受注者）」として登録を完了
6. プロフィールページへ遷移 → 基本情報を埋める

**ポイント**
- ユーザー名は後から変更不可（本名ではなくビジネスネームを推奨）
- プロフィール完成度を上げると案件検索時の露出が上がる

### 1-2. 本人確認

1. マイページ → 「本人確認書類の提出」
2. 提出可能な書類：
   - 運転免許証（表裏）
   - パスポート（顔写真ページ + 住所記載ページ）
   - マイナンバーカード（表面のみ）
   - 住民基本台帳カード（顔写真付き）
3. 画像をアップロード → 審査（通常1〜3営業日）
4. 承認されるとプロフィールに「本人確認済み」バッジが表示

**注意**
- 本人確認は任意だが、クライアントからの信頼度が大きく変わる
- 高単価案件では本人確認済みが応募条件になるケースも多い

### 1-3. 振込先設定

1. マイページ → 「報酬」 → 「振込先口座」
2. 銀行名・支店名・口座種別・口座番号・口座名義を入力
3. 登録完了

**推奨**
- **楽天銀行**を登録すると振込手数料が100円（他行は500円）

### 1-4. クイック出金の有効化

CrowdWorksのクイック出金は特別な設定不要。条件を満たせば利用可能。

**利用条件**
- 本人確認済み
- 振込先口座の登録済み
- 未出金報酬が520円以上（手数料分を差し引いた額が振込可能）

**使い方**
1. マイページ → 「報酬」 → 「クイック出金」
2. 出金希望額を入力
3. 申請 → 4営業日以内に振込

### 1-5. 手数料・出金サイクル

#### システム手数料（報酬から天引き）

| 報酬額 | 手数料率 |
|--------|----------|
| 20万円超 | 5% |
| 10万円超〜20万円以下 | 10% |
| 10万円以下 | 20% |
| タスク案件 | 20% |

#### 振込手数料

| 振込先 | 手数料 |
|--------|--------|
| 楽天銀行 | 100円 |
| その他の銀行 | 500円 |

#### 出金サイクル

| 方式 | 締め日 | 振込日 |
|------|--------|--------|
| 随時出金 | 15日 / 月末 | 締め日の15日後 |
| キャリーオーバー | 手動申請 | 申請後15営業日以内 |
| クイック出金 | 即時申請 | 4営業日以内 |

- 通常出金：15日締め→月末振込 / 月末締め→翌月15日振込
- 最低出金額：520円（クイック出金）、1,000円（通常出金）

## 2. ココナラ

### 2-1. 新規登録

1. https://coconala.com にアクセス
2. 「会員登録（無料）」をクリック
3. 登録方法を選択：
   - メールアドレス
   - Google / Apple / Facebook / Yahoo!アカウント
4. メール認証 → ユーザー名・パスワード・生年月日を入力
5. 登録完了

**ポイント**
- ユーザー名は後から変更可能
- 登録後すぐに出品が可能

### 2-2. 本人確認

1. マイページ → 「設定」 → 「本人確認」
2. 提出可能な書類：
   - 運転免許証
   - パスポート
   - 住民基本台帳カード（顔写真付き）
   - マイナンバーカード（表面のみ）
   - 健康保険証 + 住民票
3. eKYC（スマホでの顔認証+書類撮影）または画像アップロード
4. 審査（通常1〜3営業日）
5. 承認 → プロフィールに「本人確認済み」バッジ

**注意**
- 本人確認済みでないと、購入者からの信頼が低くなる
- 一部のサービスカテゴリでは本人確認が出品条件

### 2-3. 振込先設定

1. マイページ → 「設定」 → 「売上管理」 → 「振込先口座」
2. 銀行名・支店名・口座種別・口座番号・口座名義を入力
3. 登録完了

**推奨**
- どの銀行でも振込手数料は一律160円
- 3,000円以上の振込で手数料が無料になるキャンペーンが不定期にある場合あり

### 2-4. 出品者プロフィール設定

1. マイページ → 「プロフィール編集」
2. 設定すべき項目：
   - **プロフィール画像**：顔写真またはビジネス感のあるアイコン
   - **カバー画像**：任意（設定すると目立つ）
   - **自己紹介文**（最大2,000文字）：スキル・実績・対応可能範囲
   - **スキル/ツール**：タグ形式で登録
   - **ポートフォリオ**：過去の成果物を画像で登録
   - **稼働状況**：「対応可能」に設定
   - **最終ログイン表示**：「表示する」推奨（アクティブ感）
3. 「出品者ステータス」を確認 → 未設定項目を埋める

### 2-5. 手数料・出金サイクル

#### システム手数料（売上から天引き）

| 手数料率 | 備考 |
|----------|------|
| **22%**（税込） | 全サービス一律 |

#### 振込手数料

| 振込額 | 手数料 |
|--------|--------|
| 3,000円未満 | 160円 |
| 3,000円以上 | 160円 |

※一律160円（銀行問わず）

#### 出金サイクル

| 方式 | 締め日 | 振込日 |
|------|--------|--------|
| 通常出金 | 月末 | 翌月末 |

- 最低出金額：161円（手数料差引後1円以上）
- 売上の有効期限：売上確定から120日（期限内に振込申請しないと失効する場合があるので注意）
- 自動振込設定あり（毎月自動で振込申請される）

## 3. ランサーズ

### 3-1. 新規登録

1. https://www.lancers.jp にアクセス
2. 「無料で登録する」をクリック
3. 登録方法を選択：
   - メールアドレス
   - Google / Facebook / LinkedIn / Appleアカウント
4. メール認証 → ユーザー名・パスワード・氏名・住所を入力
5. フリーランサーとして登録完了

**ポイント**
- 氏名・住所は正確に入力（出金条件に関係する）
- 登録後、スキル・経験のアンケートがある → 丁寧に回答すると案件マッチング精度が上がる

### 3-2. 本人確認

1. マイページ → 「設定」 → 「本人確認」
2. 提出可能な書類：
   - 運転免許証（表裏）
   - パスポート
   - マイナンバーカード（表面のみ）
   - 住民基本台帳カード（顔写真付き）
3. 画像アップロード → 審査（通常1〜3営業日）
4. 承認 → プロフィールに「本人確認済み」マーク

**注意**
- 本人確認はランク制度にも影響する
- 出金の必須条件

### 3-3. 振込先設定

1. マイページ → 「報酬出金管理」 → 「振込先口座設定」
2. 銀行名・支店名・口座種別・口座番号・口座名義を入力
3. 登録完了

**推奨**
- **楽天銀行**を登録すると振込手数料が110円（他行は550円）

### 3-4. ランク制度

ランサーズには実績に応じたランクがあり、案件獲得率に直結する。

| ランク | 条件（目安） | メリット |
|--------|-------------|----------|
| レギュラー | 登録直後 | 基本機能のみ |
| ブロンズ | 受注実績1件以上 | ランク表示 |
| シルバー | 獲得報酬1万円以上 + 高評価 | 検索上位、案件紹介 |
| ゴールド | 獲得報酬10万円以上 + 高評価 + 納品率 | スカウト増加 |
| 認定ランサー | 総合的に高評価 | 最上位表示、専用案件 |

**ランクアップのコツ**
- 初期はタスク案件・小型プロジェクトで実績を積む
- 返信速度・納期遵守・クライアント評価が影響
- プロフィール完成度もランク判定に含まれる

### 3-5. 手数料・出金サイクル

#### システム手数料（報酬から天引き）

| 報酬額 | 手数料率 |
|--------|----------|
| 20万円超 | 5% |
| 10万円超〜20万円以下 | 10% |
| 10万円以下 | 16.5% |

#### 振込手数料

| 振込先 | 手数料 |
|--------|--------|
| 楽天銀行 | 110円 |
| その他の銀行 | 550円 |

#### 出金サイクル

| 方式 | 締め日 | 振込日 |
|------|--------|--------|
| 自動出金（15日締め） | 毎月15日 | 当月末 |
| 自動出金（月末締め） | 毎月月末 | 翌月15日 |
| キャリーオーバー | 手動 | 次の締め日に合算 |
| 即時出金（フリーナンス経由） | 即時 | 当日〜翌日 |

- 最低出金額：1,000円以上
- 即時出金の手数料：5%（+振込手数料）
- 即時出金の条件：GMOあおぞらネット銀行口座が必須、1万円〜50万円の範囲

## 4. 3PF比較表（手数料・出金サイクル）

### システム手数料比較

| 報酬額 | CrowdWorks | ランサーズ | ココナラ |
|--------|-----------|-----------|---------|
| 10万円以下 | 20% | 16.5% | 22% |
| 10万円超〜20万円 | 10% | 10% | 22% |
| 20万円超 | 5% | 5% | 22% |

**→ 高単価案件はCW/ランサーズが有利、ココナラは一律22%**

### 振込手数料比較

| 銀行 | CrowdWorks | ランサーズ | ココナラ |
|------|-----------|-----------|---------|
| 楽天銀行 | 100円 | 110円 | 160円 |
| その他 | 500円 | 550円 | 160円 |

**→ 楽天銀行ならCW/ランサーズが最安、それ以外はココナラが最安**

### 通常出金の最短着金日数

| PF | 最短パターン | 日数 |
|-----|-------------|------|
| CrowdWorks | 15日締め→月末振込 | 16〜17日 |
| ランサーズ | 15日締め→月末振込 | 16〜17日 |
| ココナラ | 月末締め→翌月末振込 | 約30日 |

### 即時出金の比較

| 項目 | CrowdWorks | ランサーズ | ココナラ |
|------|-----------|-----------|---------|
| サービス名 | クイック出金 | 即時出金（フリーナンス） | なし |
| 手数料 | 振込手数料のみ | 5% + 振込手数料 | — |
| 最短着金 | 4営業日 | 当日〜翌日 | — |
| 条件 | 本人確認+口座登録 | GMOあおぞらネット銀行必須 | — |

### 総合おすすめ

| 目的 | おすすめPF |
|------|-----------|
| 手数料を最小化（高単価） | CrowdWorks or ランサーズ |
| 最速で着金 | ランサーズ（即時出金） |
| 手数料を最小化（低単価） | ランサーズ（16.5%） |
| 自分からサービスを売りたい | ココナラ |
| 案件の数・バリエーション | CrowdWorks |

## 登録完了後のチェックリスト

### 全PF共通

- [ ] 本人確認の申請を完了した
- [ ] 振込先口座（楽天銀行推奨）を登録した
- [ ] プロフィールを作成した（→ `acquisition_workflow.md` を参照）
- [ ] プロフィール画像を設定した

### CrowdWorks

- [ ] スキル・経歴を登録した
- [ ] 希望報酬額を設定した
- [ ] 出金方式を確認した

### ココナラ

- [ ] 出品者プロフィールを設定した
- [ ] 稼働状況を「対応可能」にした
- [ ] サービスを1件以上出品した（→ `acquisition_workflow.md` Step 3参照）

### ランサーズ

- [ ] スキル・経歴を登録した
- [ ] 出金方式を「自動出金（15日締め）」に設定した
- [ ] ランクアップのためタスク案件を探した
