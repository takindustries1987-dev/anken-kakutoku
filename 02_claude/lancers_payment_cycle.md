# ランサーズ出金サイクル調査レポート

## 調査日：2026年3月1日

---

## 1. 通常出金の締め日と振込日

### 出金スケジュール（2パターン）

ランサーズは2つの出金方式から選択できます：

#### パターンA：毎月15日締め、当月末支払い
- **締め日：** 毎月15日
- **振込日：** 同月の月末（31日）
  - 2026年3月の場合：3月15日締め → 3月31日振込

#### パターンB：毎月月末締め、翌月15日支払い
- **締め日：** 毎月月末（30日または31日）
- **振込日：** 翌月15日
  - 2026年3月の場合：3月31日締め → 4月15日振込

### 重要な注記
- **祝日対応：** 支払日が土日祝日の場合、前営業日が支払い日になります

### 振込の必須条件
出金を受けるには、締め日時点で以下のすべての条件を満たす必要があります：
- ランサーズ口座残高の合計が **1,000円以上**
- 本人確認が承認済み
- 報酬出金管理ページで正しい銀行口座情報を登録
- 出金方式を「自動出金方式」に設定
- プロフィールに漢字氏名と正確な住所を記載

## 2. 即時出金の手数料と最短着金日数

### 即時出金（当日～翌日払い）の概要

**対応サービス：** フリーナンスを経由した即日・翌日振込

#### 手数料体系

| 手数料区分 | 金額 |
|-----------|------|
| 即日払い手数料 | **5%** |
| ランサーズ振込手数料（楽天銀行宛） | 110円 |
| ランサーズ振込手数料（その他の銀行宛） | 550円 |
| フリーナンス振込手数料 | 0円（手数料なし） |

**例：** 100,000円を即時出金する場合
- 即日払い手数料：5,000円（5%）
- ランサーズ振込手数料：110円～550円
- **着金額：** 約94,500円～94,890円

#### 最短着金日数
- **当日～翌日中**に指定の口座に振込

### 即時出金の利用条件（すべて必須）
1. 本人確認済み（ランサーズ + フリーナンス両方で完了）
2. 自動出金方式を選択
3. **振込先口座：GMOあおぞらネット銀行のみ対応**
4. 即日払い対象金額：¥10,000 ～ ¥500,000（手数料5%を引いた後の金額）
5. フリーナンスへの会員登録完了
6. 過去にランサーズで1回以上の出金実績がある
7. 日本国内に居住

### 利用上の注意
- 前回のフリーナンスへの振込に失敗している場合、次の成功まで利用不可
- フリーナンスへの振込中は銀行口座情報を変更できない

## 3. エスクロー（仮払い）から検収完了→出金申請→着金までの最短日数

### エスクロー（仮払い）の仕組み

```
プロジェクト契約成立
    ↓
クライアントがランサーズにエスクロー入金（報酬額）
    ↓
フリーランサーが納品・検収
    ↓
クライアントが検収完了を承認
    ↓
報酬がフリーランサーのランサーズ口座に自動加算
    ↓
次の出金締め日に自動振込
```

### 検収完了から着金までの最短パターン

| 段階 | 期間 | 説明 |
|------|------|------|
| **検収完了** | 当日 | クライアント承認時 |
| **口座加算** | 当日～翌日 | ランサーズシステムへの反映 |
| **出金申請** | 自動 | 自動出金方式の場合、締め日に自動申請 |
| **着金** | 最短3～5営業日 | 通常出金の場合 |
| **着金（即時出金）** | 当日～翌日 | 即時出金サービス利用時 |

### パターンA：通常出金で最速の場合（15日締め）
- 1月15日までに検収完了
- → 1月31日に自動振込
- **最短：** 16日～17日で着金

### パターンB：通常出金で最速の場合（月末締め）
- 2月1日に検収完了
- → 2月28日締めで自動申請
- → 3月15日に振込
- **最短：** 42日で着金

### パターンC：即時出金を利用する場合（最速）
- 検収完了後、即座に即時出金を申請
- **最短：** 1～2日で着金

**注意：** 即時出金は5%の手数料がかかるため、金銭的には最適ではない場合があります。

## 4. 2026年3月の出金スケジュール

### 自動出金方式（15日締め / 月末支払い）利用時

| 対象期間 | 締め日 | 支払日 | 備考 |
|---------|--------|--------|------|
| 2月16日～3月15日 | **3月15日（日）** | **3月16日（月）** | 15日が日曜のため前営業日に繰下げ |
| 3月16日～3月31日 | **3月31日（火）** | **3月31日（火）** | 同月末支払い |

### 自動出金方式（月末締め / 翌月15日支払い）利用時

| 対象期間 | 締め日 | 支払日 | 備考 |
|---------|--------|--------|------|
| 2月1日～2月28日 | **2月28日（金）** | **3月15日（日）** | **→ 3月14日（金）** に前倒し |
| 3月1日～3月31日 | **3月31日（火）** | **4月15日（火）** | 通常通り |

### 3月の主要な出金日

- **3月14日（金）：** 2月分出金（月末締め方式利用者）
- **3月16日（月）：** 3月上旬分出金（15日締め方式利用者）
- **3月31日（火）：** 3月下旬分出金（15日締め方式利用者）

## 追加情報：振込手数料の節約方法

### 楽天銀行の活用がお得
- **楽天銀行への振込：** 110円
- **その他の銀行への振込：** 550円
- **差額：** 440円/回

月2回の出金で880円/月の節約が可能です。

### キャリーオーバー方式との比較
- **自動出金方式：** 毎月自動振込（振込手数料が毎回かかる）
- **キャリーオーバー方式：** 手動で出金時期を選択（手数料を最小化できる）

## 結論：最速で資金を得るには

### 通常出金の場合（手数料最小）
- **最短日数：** 16～17日
- **最適方式：** 毎月15日締め、当月末支払い方式
- **推奨口座：** 楽天銀行（手数料110円）

### 即座に資金が必要な場合（手数料あり）
- **最短日数：** 1～2日
- **手数料：** 5%（+振込手数料）
- **条件：** GMOあおぞらネット銀行口座が必須

### 3月の推奨スケジュール（案件獲得者向け）
1. **3月1日～15日までに検収完了** → 3月16日に約1,000円以上が着金
2. **3月16日～31日までに検収完了** → 3月31日に着金
3. **急ぎの場合** → 即時出金で当日～翌日着金（5%手数料）
